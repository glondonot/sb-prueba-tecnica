=== 4) Caso alterno: el fix llegó a main como MERGE COMMIT de un Pull Request ===
Intentar cherry-pick de un merge commit sin indicar el padre falla:

$ git cherry-pick -x 0e253f378bd2c73f267482eafdbe5c4d7f366a82
error: commit 0e253f378bd2c73f267482eafdbe5c4d7f366a82 is a merge but no -m option was given.
fatal: cherry-pick failed
